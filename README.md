# TinyWebServer

基于 C++17 开发的轻量级、高性能 HTTP Web 服务器，专为 Linux 环境设计（测试于 Ubuntu 24.04 LTS）。本项目采用主从 Reactor 架构结合多线程技术，提供非阻塞的并发连接处理能力。



## 核心特性

- **主从 Reactor 架构**：核心采用 `TcpServer` 类管理，主事件循环负责接受新的客户端连接，多个子事件循环通过原子计数器轮询分配到独立线程中，负责处理已建立连接的底层读写事件。
- **高效 I/O 多路复用**：底层采用 Linux `epoll` 技术，套接字事件默认配置为边缘触发（`EPOLLET`）模式处理，并结合非阻塞 I/O 防止 CPU 空转。
- **异步日志系统**：实现单例模式的异步日志模块，前端通过宏提交日志至阻塞队列，后台通过独立线程结合条件变量与互斥锁异步落盘，避免阻塞核心网络线程。
- **定时器与空闲连接超时管理**：基于小根堆（`HeapTimer`）实现毫秒级定时器，为每个连接维护一个过期时间节点，读写事件触发时惰性续期；静默超过 **15 秒**的连接会被自动关闭并回收，防止僵尸连接耗尽文件描述符。
- **HTTP/1.1 支持与静态资源分发**：支持 HTTP GET 请求与 Keep-Alive 长连接维持，默认读取 `./www` 目录下的静态文件，并具备基础的防目录穿越检查与 MIME Type 解析功能。
- **事件分发与解耦**：通过 `Channel` 类封装文件描述符，绑定读、写、关闭的回调函数，实现事件监听与业务逻辑的解耦。

## 性能表现

使用 Webbench 进行压力测试，在 **1000 个客户端并发请求**下，服务器表现如下：



- **QPS (Queries Per Second)**: 48,000 次/秒
- **数据传输率**: 4.5 MB/s

## 环境配置

- **操作系统**: Linux (推荐 Ubuntu 24.04 LTS)
- **编译器**: g++ (完全支持 C++17 标准)   
- **构建工具**: Make

## 构建与运行

1. **克隆项目到本地**

   Bash

   ```
   git clone git@github.com:AsherIsNotBot/TinyWebserver.git
   cd TinyWebserver
   ```

2. **编译项目** 项目提供标准的 Makefile，直接在根目录执行编译指令（自动链接 `-pthread` 并开启 `-O2` 优化）：   

   Bash

   ```
   make
   ```

3. **启动服务器** 编译完成后会在当前目录生成 `server` 可执行文件。运行该文件，服务器将默认绑定本地地址并监听 `8080` 端口：   

   Bash

   ```
   ./server
   ```

   *启动后，可通过浏览器访问 `[http://127.0.0.1:8080](http://127.0.0.1:8080)` 验证服务。*

4. **清理构建文件** 如需清理编译生成的 `.o` 对象文件和 `server` 可执行程序，执行以下命令：   

   Bash

   ```
   make clean
   ```
